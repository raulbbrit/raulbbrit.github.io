Churn prediction, from EDA to deployment

Group project from the FIAP graduate program, IBM Telco dataset

Problem. Predict which telecom customers will cancel and serve the model through an API.

My part. I set up the engineering foundation (uv, ruff, pre-commit and CI on GitHub Actions with lint, tests and branch protection). In the exploratory analysis I found two data leaks and removed them from the model, and I formalized the data contract with Pandera. I modularized training with over 1,600 lines of pytest tests.

Result. A Random Forest served by FastAPI in Docker from the MLflow Model Registry.

PR-AUC in cross-validation0.775
Recall on the test set0.81
