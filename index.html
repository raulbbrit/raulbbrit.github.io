Previsão de churn, do EDA ao deploy

Projeto em grupo da pós-graduação na FIAP, dataset IBM Telco

Problema. Prever quais clientes de telecom vão cancelar e servir o modelo por uma API.

Minha parte. Montei a base de engenharia (uv, ruff, pre-commit e CI no GitHub Actions com lint, testes e proteção de branch). Na análise exploratória, achei dois vazamentos de dados e os excluí do modelo, e formalizei o contrato de dados com Pandera. Modularizei o treino com mais de 1.600 linhas de testes em pytest.

Resultado. Random Forest servido por FastAPI em Docker a partir do Model Registry do MLflow.

PR-AUC na validação cruzada0,775
Recall no conjunto de teste0,81
